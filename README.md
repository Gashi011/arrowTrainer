# Arrow Funkcije Trener

Mini aplikacija sa 40 progresivnih zadataka za JavaScript arrow funkcije.

## Pokretanje
Otvori `index.html` u browseru.

## Fajlovi
- `index.html` — HTML struktura
- `style.css` — CSS izgled
- `script.js` — zadaci, testovi, napredak i JavaScript logika

Napredak se čuva lokalno u browser `localStorage` memoriji.


## PWA instalacija
Ova verzija je PWA (Progressive Web App — instalabilna web aplikacija).

Dodatni fajlovi:
- `manifest.webmanifest`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

### GitHub Pages
U GitHub repository-ju:
1. Settings
2. Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: /(root)
6. Save

Nakon deploy-a otvori GitHub Pages adresu na telefonu u Chrome-u i iz menija izaberi **Install app**.

Ako je ranija verzija sajta već bila otvorena, uradi refresh ili zatvori i ponovo otvori stranicu da browser preuzme novi manifest i service worker.
